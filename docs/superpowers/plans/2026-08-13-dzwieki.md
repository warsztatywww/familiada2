# Nowe efekty dźwiękowe — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wpiąć 8 nowych, nazwanych efektów dźwiękowych Familiady w zdarzenia gry na tablicy (`/board`), zastępując stare trzy dźwięki i beepy WebAudio.

**Architecture:** Tablica reaguje na zdarzenia serwera (`msg.event`) i odtwarza dźwięki na dwóch logicznych kanałach: SFX (krótkie, nakładające się, każdy własny `<audio>`) i jingiel (długie stingi, jeden na raz — nowy ucina poprzedni). Jeden nowy szczegół protokołu: `timerStart` przenosi `player` (1/2), żeby tablica wiedziała, kiedy zagrać jingiel „po 1 rundzie finału".

**Tech Stack:** Node ESM, `node:test`; frontend vanilla JS bez build stepu; elementy `<audio>` HTML.

**Spec:** `docs/superpowers/specs/2026-08-13-dzwieki-design.md`

## Global Constraints

- Dźwięk gra wyłącznie tablica (`/board`) — nigdy host ani buzzery.
- Zero bibliotek front-endu, zero build stepu, zero zasobów z sieci.
- ESM; `npm test` (`node --test`) w pełni zielone, w tym istniejące 50 testów.
- `apply(state, cmd)` mutuje stan i zwraca zdarzenie albo `null`; komendy nieprawidłowe zwracają `null` bez mutacji.
- Pliki dźwięków są już w `public/assets/sounds/` (8 plików `*-familiada.mp3`); stare `correct.mp3`/`error.mp3`/`brawo.wav` są usunięte.
- Commit po każdym tasku (branch `main`, zgoda użytkownika).

- [ ] **Step 2: Zastąp `beep` i `play` helperami `playSfx`/`playJingle` w `public/board.js`**

Usuń funkcję `beep` (WebAudio) i funkcję `play`. Zachowaj `const audioCtx = new AudioContext();` (używa go bramka startowa przez `audioCtx.resume()`).

Obecny fragment do usunięcia:

```js
function beep(freq, ms, gainVal = 0.3) {
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  osc.frequency.value = freq;
  osc.type = 'square';
  gain.gain.value = gainVal;
  osc.connect(gain).connect(audioCtx.destination);
  osc.start();
  osc.stop(audioCtx.currentTime + ms / 1000);
}

function play(id) {
  const el = $(id);
  el.currentTime = 0;
  el.play().catch(() => {}); // audio odblokowane bramką startową; catch na wszelki wypadek
}
```

Wstaw w to miejsce:

```js
// Kanał SFX: krótkie efekty, mogą się nakładać (każdy własny <audio>).
function playSfx(id) {
  const el = $(id);
  el.currentTime = 0;
  el.play().catch(() => {}); // audio odblokowane bramką startową; catch na wszelki wypadek
}

// Kanał jingla: długie stingi — nowy zatrzymuje poprzedni, żeby dwa się nie zderzyły.
const JINGLES = ['jingle-break', 'jingle-prefinal', 'jingle-after1'];
function playJingle(id) {
  for (const j of JINGLES) { const el = $(j); el.pause(); el.currentTime = 0; }
  const el = $(id);
  el.currentTime = 0;
  el.play().catch(() => {});
}
```

- [ ] **Step 3: Przepisz `handleEvent` w `public/board.js` wg mapy**

Zastąp całą funkcję `handleEvent` (od `function handleEvent(event) {` do jej klamry zamykającej — zachowaj case `'intro'` bez zmian):

```js
function handleEvent(event) {
  switch (event.type) {
    case 'reveal':
    case 'round-won':
    case 'steal-success':
    case 'final-reveal':
    case 'cheap-reveal':
      playSfx('snd-good');
      break;
    case 'strike':
    case 'strike-out':
    case 'steal-fail':
      playSfx('snd-bad');
      flashBigX();
      break;
    case 'final-miss':
      playSfx('snd-bad'); // zła odpowiedź w finale — bez ikony X
      break;
    case 'buzz':
      playSfx('snd-buzz');
      break;
    case 'repeat':
      playSfx('snd-final-repeat');
      break;
    case 'new-round':
      playJingle('jingle-break');
      break;
    case 'final-start':
      playJingle('jingle-prefinal');
      break;
    case 'timer-start':
      if (event.player === 2) playJingle('jingle-after1');
      break;
    case 'intro': {
      // Ponowne kliknięcie "Intro" w trakcie odtwarzania = replay od początku.
      if (lastState?.phase !== 'idle') break;
      const video = $('intro-video');
      const music = $('snd-intro');
      video.currentTime = 0;
      video.play().catch(() => {});
      music.currentTime = 0;
      music.play().catch(() => {});
      break;
    }
  }
}
```

Przez `browser_evaluate` podmień `HTMLMediaElement.prototype.play`, żeby zliczać, który element gra, i steruj grą przez WebSocket. Sprawdź dla reprezentatywnych zdarzeń, że gra właściwy element:

```js
// w kontekście strony:
window.__plays = [];
const origPlay = HTMLMediaElement.prototype.play;
HTMLMediaElement.prototype.play = function () { window.__plays.push(this.id); return origPlay.call(this).catch(() => {}); };
const ws = new WebSocket(`ws://${location.host}`);
await new Promise(r => ws.onopen = r);
const cmd = c => ws.send(JSON.stringify({ type: 'command', cmd: c }));
```

Zdarzenia do przejścia i oczekiwany `id` w `window.__plays`:
- `newRound {roundIndex:0}` → `jingle-break`
- `reveal {index:0}` → `snd-good`
- `strike {team:0}` → `snd-bad` (i wielki X mignął)
- `buzz {team:0}` po `newRound` (stage buzzers) → `snd-buzz`
- `startFinal` → `jingle-prefinal`
- `finalSet {qIndex:0, player:0, answerIndex:0}` → `snd-good`
- `finalSet {qIndex:1, player:0, answerIndex:null}` → `snd-bad`
- `repeatBuzzer` → `snd-final-repeat`
- `timerStart {seconds:20, player:2}` → `jingle-after1`; a `timerStart {seconds:15, player:1}` → **brak** nowego jingla
